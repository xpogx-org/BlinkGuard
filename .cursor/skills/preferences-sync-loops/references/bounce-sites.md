# Known bounce sites (`sendPreferences`)

Review these when touching prefs IPC:

- `PreferenceActions.updateLocale` (must early-return if locale unchanged; also invalidates blink-stats charts)
- `PreferenceActions.resetPreferences`, `PreferenceActions.applyBackup` (prefs scope; one echo)
- `PreferenceActions.applySettingsProfile` (named setups switch; **one** `sendPreferences` after per-key snapshot write — renderer must **not** fan out `update-*` / `pushPreferenceDiff`; after echo `lastSyncedRef` equals live so diff is empty)
- `PreferenceActions.appendPauseAppFromLastExternal` (tray **Pause for {app}**; one `sendPreferences` echo so Settings list + Setups dirty-state update; `focusPause.recompute()` on live foreground)
- `popupEditorSaved` in `register-ipc-handlers.ts` (geometry persist + echo for `current` / `all`; writes position/size maps + `popupPosition` / `popupSize` mirrors; `scope: "all"` copies layout to every live display and closes the editor; `scope: "current"` closes unless another live display is unset, then `hasNextUnsaved` on `currentPopupState`; `scope: "next"` moves the editor only — **no** persist and **no** `sendPreferences`)
- Popup geometry recover in `WindowManager.ensurePopupPosition` / display listeners (`display-removed` / `display-metrics-changed` → `recoverOpenPopupPositions`): **do not persist** maps on visual recover or display disconnect (disconnected ids stay so the layout returns with the screen). Persist maps + optional mirrors + `sendPreferences` only on user Save / legacy seed / workArea-relative migrate / cap eviction; equal writes no-op via `PreferencesService`. `popupPositionsByDisplayId` and `popupSizesByDisplayId` are compared in `sameRendererPrefs` but **not** pushed from the renderer (`pushPreferenceDiff` has no channel for either).
- `PreferenceActions.showCameraWindow` (only if main enabled camera)
- `main.ts` `onCalibrationComplete` → persist EAR + `calibrationAt` + personal classifier overlay + `sendPreferences` when baseline or bias changes
- Global shortcut toggle + `ReminderService.resumeAfterSleep` / auto-stop-no-face stop (tracking snapshot)
- Main-window `did-finish-load` / initial hydrate (expected one-shot)

**Not** bounce sites (no `sendPreferences` today): `updateHasCompletedOnboarding`, blink-stats request/reset/spend, `updateGoalsConfig`, look-away interval/duration/title/hint / coaching threshold updates, `updateInterval` / `updateMicroBreakInterval` / `updateBlinkPromptProfile` (persist + `reminders.applyReminderInterval()` so a live session picks up the cadence; no prefs echo), `updateEyeCareIndependentOfTracking`, `updateKeyboardShortcuts` (persist + `registerAll` only; no prefs echo), `updateClassifierCalibration` (persist + sidecar apply; no prefs echo — calibration complete in main is the echo site), `updateCameraQuality` / `updateCameraDevice` (persist + sidecar apply; stamping the real OpenCV index after open does **not** echo prefs), `updateQuietHours*` / `updateQuietHoursByWeekday` / `updatePauseOnFullscreen` / `updatePauseAppRules` (persist + `focusPause.recompute()` + tray menu rebuild via `onPauseAppRulesChanged`; **no** prefs echo — tray add uses `appendPauseAppFromLastExternal` which **does** echo), `updateNotificationStyle` (persist only; native player reads live prefs), `listPauseAppCandidates` / `listCameraDevices` (invoke; picker snapshot only, never prefs), `camera-capture-status` (receive-only status push; no `sendPreferences`), `shellReady` (cold-start tracking restore gate only), `updateCalibrationNudgeEnabled` / `dismissCalibrationNudge` / live `calibration-nudge` (reason push only; `calibrationAt` / dismiss / drift stamps are main-owned and not renderer-pushed) — keep it that way unless another surface truly needs a full prefs echo.
