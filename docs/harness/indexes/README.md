# Indexes

Always-on TOC. Open a per-area file only when that area is in play.

| Area | File | When to open |
|---|---|---|
| UI | `ui.md` | Layout, components, copy, navigation, popups |
| Logic | `logic.md` | Domain rules, application services, orchestration |
| Styles | `styles.md` | Tokens, themes, CSS |
| IPC / API | `ipc.md` | Contracts between processes or clients |
| Tooling | `tooling.md` | Verify command, lint/test/build, Cloud VM, `/deploy` |
| Sidecar | `sidecar.md` | Optional camera blink-detector |
| Tray | `tray.md` | Tray menu, hush, pause |

Setup copies only rows that match the repo. Add rows when a new surface appears. Keep each area file to what / where / when-to-open.
